# XEMBRA MOTIVE

Reproducibility archive for synthetic MOTIVE memory-gating experiments.

## Freeze discipline
- Preserve completed experiment source and outputs unchanged.
- Replications belong in separate directories (for example `motive-57r/`).
- Report negative results and limitations.
- Pin seeds and dependencies, record SHA-256 hashes, and distinguish archived results from independently reproduced results.

These experiments do not establish consciousness or subjective wanting.
